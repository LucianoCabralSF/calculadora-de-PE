# Calculadora do Controller

Ferramenta web (abre direto no navegador, sem instalar nada) para o Controller enxergar o custo de **vários ângulos**, com base no material *Custos, Sistemas de Custeio, Gestão e Formação de Preço*.

Funciona em dois modos: **Produtos** (indústria/comércio) e **Serviços**, cada um com seu exemplo e seus dados salvos no navegador.

| Aba | O que responde |
|---|---|
| Painel 360 | Resumo: margem de contribuição, custo cheio, equilíbrios, margem de segurança, capacidade, alavancagem e leitura automática |
| Absorção x Variável | A armadilha do rateio: custo cheio x margem de contribuição, efeito do volume e do estoque |
| Equilíbrio e CVL | Ponto de equilíbrio contábil, financeiro e econômico, gráfico e simulador de desconto |
| Pedido / Proposta especial | Aceitar ou não um pedido com capacidade ociosa, com checklist estratégico (marca, canal, precedente de preço) |
| Mix e gargalo | Melhor uso do recurso escasso (margem por hora) |
| Custeio ABC | Rateio tradicional x ABC por atividades e direcionadores |
| Formação de preço | Markup, custo-meta (target costing) e faixa piso–markup–mercado |
| Conceitos | Glossário: gasto, custo, despesa, investimento, perda e métodos |

Exemplo de Produtos: caso Microcervejaria Lúpulo Dourado. Para usar, abra `index.html`.
